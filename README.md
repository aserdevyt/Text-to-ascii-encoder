This is a simple script written in Python that converts characters to the ASCII code.

## Installation

### 1. on Linux (and maybe FreeBSD):

#### Use the bash script

```bash
git clone https://github.com/Szerwigi1410/Text-to-ascii-encoder.git
cd Text-to-ascii-encoder
chomd +x install.sh
./install.sh
```

#### use pacman

##### use [aserdev-repo](https://github.com/aserdevyt/aserdev-repo)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/aserdevyt/aserdev-repo/refs/heads/main/install.sh)
```

##### install using pacman

```bash
sudo pacman -Sy ascii-enc
```

### 2. On macOS and Windows

 - Just download the ```ascii-enc.py``` file
 - And run it with ```python3 ascii-enc.py``` 
 - Or run it inside IDLE

## usage

### intractive mode

```bash
./ascii-enc.py
```

### convert to ascii 

```bash
./ascii-enc.py [string]
```

### convert to ascii in a list

```bash
./ascii-enc.py -l [string]
```

### convert to string from ascii

```bash
./ascii-enc.py -r [string]
```

### more details

```bash
./ascii-enc.py -h
```
